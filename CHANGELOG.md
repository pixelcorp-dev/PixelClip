# Changelog

What changed in PixelClip for people using the product. Newest dates are first.

## 2026-11-22

- **New:** PixelClip is now a self-hosted-only tool by PixelDominion. The hosted marketing site, pricing pages, blog, legal pages, and app-store links are gone; the app opens straight into the tool.
- **New:** A detailed self-hosting guide in [`SELF-HOSTING.md`](SELF-HOSTING.md) covering requirements, API keys, fully local Whisper and Ollama setups, GPU rendering, backups, updates, and troubleshooting.
- **Improved:** The self-hosted card in the upgrade dialog links to that guide instead of an external website.
- **Under the hood:** Everything is renamed from SupoClip to PixelClip: packages, containers, Docker volumes, environment-variable prefixes, the MCP package, and the systemd units.
- **Under the hood:** The source license file is removed and the project is a full recreation made by PixelDominion.
